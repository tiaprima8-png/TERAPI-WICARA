# AbiBicara Pro - Pediatric Speech & Oral-Motor Trainer

Aplikasi Android terapi wicara & senam motorik oral mandiri di rumah untuk anak usia 3 tahun (fokus mengatasi *Initial Syllable Deletion* / penghilangan suku kata awal dan merangkai 2 kata).

---

## Unduh File APK Langsung (Tersimpan di GitHub)

File APK siap instal sudah tersimpan langsung di repositori ini pada folder **`releases/`**:

- **Lokasi File APK di Repo:** [`releases/AbiBicara-Pro.apk`](releases/AbiBicara-Pro.apk)
- **Cara Unduh di GitHub:**
  1. Klik file **[`releases/AbiBicara-Pro.apk`](releases/AbiBicara-Pro.apk)** di daftar file GitHub.
  2. Klik tombol **"Download raw file"** (ikon unduh di sebelah kanan).
  3. Buka file `AbiBicara-Pro.apk` di HP Android Anda dan instal.

Selain di folder `releases/`, setiap perubahan kode yang di-*push* ke GitHub akan otomatis menjalankan **GitHub Actions** (`.github/workflows/build-apk.yml`) yang memperbarui file APK di menu **Actions** dan **Releases**.

## 5 Modul Utama Aplikasi
1. **Jadwal & Panduan ("Jadwal"):** Dashboard kesiapan bicara, checklist rutinitas 4 waktu (Pagi, Siang, Sore, Malam) tersimpan otomatis di database lokal (Room), dan Kartu Saku *Do's & Don'ts* Orang Tua.
2. **Simulator Pijat & Senam Rahang ("Senam Rahang"):** Panduan interaktif 4 tahap (Pijat TMJ & Pipi, Lip Tapping, Auman Singa A-O-U, dan Jaw Prompting) dengan visualisasi animasi bukaan rahang dan Timer Hitung Mundur.
3. **Studio Latihan 2 Kata & Cermin Kamera ("Latihan"):** *Live Front Camera Mirror* dengan bingkai panduan mulut Abi & Adik, Papan Ketuk Suku Kata (*Syllable Tap-Pad*) dengan penekanan visual pada suku kata pertama (**"BUKA RAHANG!"**), getaran *Haptic*, TTS Bahasa Indonesia tempo lambat (`0.7x`), serta perekam suara latihan 5 detik.
4. **Terapi Bernyanyi "Burung Kakaktua" ("Bernyanyi"):** Karaoke terapi tempo lambat dengan teknik *Cloze Procedure* dan mode **"Abi Berhenti Mendadak (3 Detik Tunggu Adik)"**.
5. **Rekam Medis & Tracker Progres 4 Level ("Progres"):** Evaluasi 4 Level Klinis Terapi Wicara, grafik distribusi level, catatan observasi mingguan, dan fitur **Export Laporan Progress**.
